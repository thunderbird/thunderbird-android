# Standards

Standards profiles record the exact external specifications adopted or explored by the project. Each profile defines a
capability-scoped dependency graph, local profiles and extensions, conformance boundaries, implementation evidence, and
interoperability fixtures.

- [Portable Profile Data](portable-profile-data.md) records the PDPArchive, encrypted ZIP64, mail, contact, and calendar
  specifications used or explored for portable profile data.

Profiles are updated with the same review that changes a feature's standards boundary.
